**BC©Grid**: a grid transition for Adobe Premiere Pro on Windows. The frame splits into tiles that
flip to the next shot one by one, with six reveal patterns, grid lines and a glow on each tile.

### Install

1. Close Premiere Pro.
2. Download and run **BC_Grid_Setup.exe**. If Windows says *"Windows protected your PC"*, click
   **More info → Run anyway**.
3. In Premiere: **Video Transitions → BillyCreative → BC©Grid**, drag it onto a cut.

### Files

| File | What it is |
|---|---|
| `BC_Grid_Setup.exe` | Installer (recommended) |
| `BCGrid.aex` | The plugin on its own, for manual install |
| `install.bat` | Copies `BCGrid.aex` into place (run as administrator, next to the .aex) |
| `Instalar.BC.Grid.Windows.pdf` | Install guide in Spanish |

Needs Windows 10/11 64-bit and Premiere Pro 2022 or newer.
