How to install BC©Grid

Grid transition for Adobe Premiere Pro on Windows, by BillyCreative

Install

  1. Download BC_Grid_Setup.exe from github.com/FardeenAFK/BCGrid-Windows/releases/latest. If the browser warns about the file, choose Keep.
  2. Close Premiere Pro and After Effects.
  3. Open BC_Grid_Setup.exe. If you see “Windows protected your PC”, click More info → Run anyway. If Windows asks to allow changes, click Yes.
  4. Click Next, Install, then Finish.

Use in Premiere Pro

  1. Go to Effects → Video Transitions → BillyCreative.
  2. Drag BC©Grid onto the cut between two clips.
  3. Click the transition and open Effect Controls to change the grid, pattern, lines and flash.

Use in After Effects

  1. Put two clips in a comp, one layer above the other, and select the top layer.
  2. In Effects & Presets, search BC©Grid and double-click it.
  3. Set Second clip to the other layer and hide that layer (eye icon).
  4. Keyframe Progress from 0 % to 100 %.

Manual install: copy BCGrid.aex to C:\Program Files\Adobe\Common\Plug-ins\7.0\MediaCore\BillyCreative, or run install.bat as administrator.
Uninstall: Windows Settings → Apps → BC©Grid (BillyCreative) → Uninstall.
Needs Windows 10/11 64-bit and Premiere Pro 2022 or newer. © 2026 BillyCreative
